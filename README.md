# Card_Bogolyubova
# Кинозал «Орион» — учебное бронирование мест

## Тема
Кинотеатр. Пользователь выбирает фильм, сеанс, отмечает места на схеме и подтверждает учебную бронь. Есть сохранение и отмена.

## Функции
- Афиша фильмов, переключение сеансов.
- Схема зала с креслами, зонами «Партер» и «VIP».
- Мультивыбор мест, расчёт суммы, имя зрителя.
- Сохранение в localStorage, отмена.
- Работа с клавиатуры.

## Ограничение
Учебное демо: бронирования сохраняются только в этом браузере. Реальная бронь не оформляется.
